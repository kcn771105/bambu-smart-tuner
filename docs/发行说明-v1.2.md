# Bambu Smart Tuner v1.2 发行说明

> 一句话：**它读你的 3mf，逐层量出这个模型长什么样，再按量出来的数改参数；改完能用本机 Bambu Studio 切片证明「每一项改动真的进了 gcode」。**

你现在可以：把 3mf 拖进来 → 选机型/耗材/模式（可选：打印板、室温、风扇强弱、支撑好不好拆、熨烫、特殊模式）→ 点「优化」→ 看结论卡 → 保存成 `xxx_optimized_v2_*.3mf`（原文件和上一版都保留）→ 导入 Studio 打印。

---

## 一、这一版修掉的三个老问题

| 现象 | 真根因 | 现在怎么做 |
|---|---|---|
| 参数有时生效、有时不生效 | 热床温度、风速这类键属于**耗材页**，以前只写值、没在「与预设不同」的槽位里声明 → Studio 打开时按耗材预设盖回默认值 | 三个槽位分别声明（工艺 / 耗材 / 机器），凡是改过的键都声明 |
| 选了机型后生成的 3mf 不对应 | 从来没重写机器页（`printer_model`、`printer_settings_id`、`printable_area`、机器速度/加速度上限），Studio 按旧机型算 | 换机型时同步整个机器页；只换喷嘴也不同步错，`nozzle_diameter` / `printer_variant` 一并改 |
| 手动选机型后参数又变回默认 | 同上两条叠加 | 同上 |

### 补丁：11-27 修的保存失败

「耗材页 → 新建一份耗材」点保存会报 `TypeError: the JSON object must be str, bytes or bytearray, not list`。
根因是 `filament_settings_id` 在工程文件里是数组型键（`["Bambu PLA Basic @BBL P2S"]`），
我们把 Python list 直接塞进了 settings，写盘时 `json.loads(list)` 就炸了。
现在按原形态 `json.dumps` 写回，并给 `threemf._typed_list()` 加了兜底；
30 种「耗材页 × 熨烫 × 自动」组合的保存矩阵已全部通过。

### 补丁：11-27 修的「能保存、一按切片就废」

这三个是拿真件丢进本机 Studio CLI 才暴露的：文件存得下、Studio 也打得开，
一按切片就 `process not compatible with printer` / `Param values in 3mf/config error`，一个 gcode 都不出。

| 场景 | 真根因 | 现在怎么做 |
|---|---|---|
| 换了机型切不了片 | 工程里有一句 `print_compatible_printers`（3mf 把工艺预设的兼容机型抄了一份），只改机型名它不改，Studio 仍按旧机型判不兼容 | 换机型时把它写成**当前这一台**（写整个兼容列表反而失败，实测过） |
| 只换喷嘴也切不了片 | 同上；且 `0.20mm Standard` 在新喷嘴上常常不存在 | 同时换 `print_compatible_printers` 与工艺预设名，自动挑「同机器 + 层高最接近」的（0.6 → `0.30mm Standard`）；换耗材预设**绝不跨材质** |
| 螺旋（花瓶）模式切不了片 | 它在 Studio 里是「单壁+无填充+无顶面+无支撑」一整套，不是单个开关 | 选螺旋就自动配套「墙层数 1 + 关支撑」，界面说明原因 |

## 二、新增能力

1. **按模型针对调参**：逐层采样算 悬垂面积比 / 上部悬垂占比 / 最长桥接跨度 / 细高比 / 圆度 / 体积 / 顶面占比 / 颈部收缩，据此决定层高、墙数、填充、速度、裙边、斜接缝、支撑、桥接速度。
   结论卡上会写「改动依据：按模型实测 25 / 预设基准表 14 / 保持原值 8」，能对上账。
2. **热床温度与风速：耗材 × 打印板 × 室温**。填室温（例如 12°C）→ 冷天自动抬高板温、降低风扇；「风扇强弱」可整体加减。
3. **打印板跟着工程和本机 Studio 走**：只列本机 Studio 真有的板；工程用的板本机不认识时自动换板，并把 `curr_bed_type` 一起改掉（只改温度不改板名等于白改）。
4. **支撑三档「好拆」**：标准 / 好拆（推荐）/ 极好拆，改分离间隙与接触面；有悬垂的件按几何自动决定要不要开支撑。
5. **圆柱接缝**：圆件/细高件自动对齐接缝 + 开斜接缝（scarf joint）。
6. **熨烫**：先选熨不熨、熨哪儿（只熨最顶面 / 所有朝上的面 / 所有实心层顶面 / 不熨烫），参数可自动按 耗材 × 层高 × 喷嘴 × 模式 算。
7. **「其他」页的特殊模式全部由你勾**：逐件打印、螺旋花瓶、圆弧拟合、磨砂皮肤等 8 项，默认全部「跟随工程」，只写你亲手选的，软件不替你开。
8. **耗材页怎么处理，你选**：不改耗材页（只调工艺）/ 写进当前耗材 / **新建一份耗材**（另存为「原名 + 优化」，原预设一个字不动）。
9. **全量切片核对**：保存后点「用本机 Studio 切片核对」，从 gcode 的配置块里把参数读回来，逐键三态判定 —— 生效 / 被切片器改成别的值（标红）/ 不参与切片。命令行同一套：`python -m core.cli verify 文件.3mf`（有项被改写时返回码 2）。
10. **结论卡**：一句话说清「这样调整后会变成什么样」（时长、表面、速度、附着、热床/风扇、支撑、要你看一眼的地方），不再让你对着一屏参数值猜。

## 四、安装与使用

1. 解压 `BambuSmartTuner-v1.2-win64.zip` 到任意目录（不要只解压 exe，`rules/` 和 `data/` 要跟着）。
2. 双击 `BambuSmartTuner.exe`（Windows 10/11，无需装 Python）。
3. 拖入 3mf → 选机型/耗材/模式 → 优化 → 保存。
4. 需要自己验：在「写入核对」页签点「用本机 Studio 切片核对」；**切片前先关掉正在运行的 Bambu Studio**（它只允许一个实例，开着会把命令行任务转交过去）。

## 五、已知边界（说清楚，免得期待错）

- 不是 AI 模型，是**几何量测 + 规则库**推算；覆盖 18 个机型、5 类耗材、6 种模式。
- 只能证明「参数进了切片器且没被改写」，证明不了「这个值对你的件是最优的」——最优要靠打印结果回流。
- 一份工程里有多种耗材时，热床/风扇按**第一种耗材**的基线推导。
- 腔体温度、压力提前（PA）等仍沿用耗材预设，本版不改。
- 目前 `seam_position` 的判断偏粗（只按细高比和圆度定，没考虑「最强边/最短边」），下一版会细化。
