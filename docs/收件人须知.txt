Bambu Smart Tuner v1.2.1 —— 收件人须知
================================

一句话：解压后双击 BambuSmartTuner.exe 就能用，不用装 Python，也不用装任何运行库。

------------------------------------------------------------
一、怎么开始
------------------------------------------------------------
1. 把整个文件夹解压到任意位置（不要只把 exe 单独拖出来——rules 和 data 两个
   子目录要跟它放在一起，那是规则库和「参数在 Studio 里在哪」的对照表）。
2. 双击 BambuSmartTuner.exe。首次启动约 3~8 秒（单文件程序要先解包，正常）。
3. 点「加载 3mf…」选你在 Bambu Studio 里保存的工程（.3mf 或 .bambu）。
4. 核对识别出的机型 / 耗材 / 喷嘴，再按需要设「打印板」「室温」「风扇偏置」
   「支撑好拆」「接缝斜接」这几项（不设也能跑，用默认值）。
5. 选优化模式 → 点「开始优化」→ 先看界面最上面那段**结论卡**（告诉你这次
   调完是快还是慢、表面怎样、热床风扇给了多少、支撑好不好拆），再决定要不要
   看下面的参数表。
6. 点「保存为 3mf」，文件名形如 原名_optimized_v2_时间戳.3mf。
   再次保存会另生成一份新的，**旧的一份和原工程都不会被覆盖**，可以并排比较。
7. 用 Bambu Studio 打开新生成的那份，直接切片打印。

------------------------------------------------------------
二、电脑要求
------------------------------------------------------------
· Windows 10 64 位（1809 以上）或 Windows 11
· 不需要装 Python、不需要装 .NET、不需要装 VC++ 运行库
· 不需要管理员权限，不写注册表，不改系统设置
· 不需要联网

关于 Bambu Studio：装不装都能用。
  · 装了：程序会读你本机的官方预设，用来算「和官方标准档差了多少」，
    差异声明更精准；
  · 没装：自动退化成「把所有改过的键都声明为差异」，同样能正常出文件、能切片。
    只是「Studio 里在哪」这一列会用程序内置的对照表（内容一样）。

------------------------------------------------------------
二点五、这次（v1.2.1）修了什么
------------------------------------------------------------
只在 v1.2 上修问题，没加新功能：
· 界面错位：v1.2 的「打印板/室温/风扇偏置/支撑好拆」那行被「原始值」标签压住，
  逐件明细盖住了方案下拉，③ 优化模式整块被挤出屏幕。
  现在行位重排，逐件明细/推导复核/真机同步收进下方页签，
  **结论卡固定在页签区上方**，一打开就能看到结论。
· 换喷嘴没换机型时，机器页不跟着改：0.6 喷嘴保存出来机器页还是 0.4，
  Studio 会按 0.4 切。现在会同步喷嘴相关三行。
· 打印板默认写死 Supertack：用 Textured PEI 的工程会被写成 Supertack 的板温。
  现在默认「跟随工程」，加载时按你工程里的板子自动选。
· 首层板温原来比其余层低 5°C（首层最需要抓板时反而更凉）——这是天冷翘边
  的一大半原因。现在首层比其余层高 5°C。
· 「打一个盒子降速严重」：①实心平板被误判成「薄壁/镂空」，吃到一串降速规则；
  ②首层速度被形状层和几何层按同一个理由各乘一次（50 → 36）；③降了不说为什么。
  三条都修了，结论卡里现在会直接写「速度：外壁 200→137、内壁 300→174
  （被体积流量上限 18 mm³/s 压着）」。
· 室温填完就自动生效：结论卡会写「室温 12°C：热床 70 → 78°C、风扇再降 10 个百分点」，
  不用再点别的。
· 新增「写入核对」页签：保存后逐键列出「表格里的值 / 文件里的值 / 结果」，
  确认参数真的写进了新文件（不是只显示在界面上）。
· 页签里那个「用本机 Studio 切片核对」按钮，会把**你写入的每一个键**和
  切片器实际采用的参数逐键对照（Studio 把最终参数写在 gcode 的 CONFIG_BLOCK 里）。
  结论三种：生效 / 被切片器改成别的值（这才是真没生效，会标红）/ 不参与切片。
  实测鱼缸温度计支架：写入 44 项 → 44 项全部生效。切片要几十秒，慢慢等，
  切的时候别开另一个 Bambu Studio（它只允许一个实例，会把任务抢走）。
  命令行同一套：python -m core.cli verify 文件.3mf
· 新增三个「你自己定」的开关（都在识别面板第 3 行）：
  - 耗材页：不改耗材页 / 写进当前耗材 / 新建一份耗材。
    选「新建一份耗材」时，参数照写，耗材名会变成「原名 + 优化」——
    在 Studio 的耗材列表里点「保存」就多出一份新耗材，你原来那份预设不会被改。
  - 熨烫：先选熨不熨、熨哪儿（只熨最顶面 / 所有朝上的面 / 所有实心层顶面 / 不熨烫），
    旁边「熨烫参数自动优化」勾上就由程序按耗材和层高给流量/间距/速度/图案，
    去掉就只改类型、参数保留你自己的值。
  - 特殊模式：点「特殊模式…」按钮，把「其他」页那几个开关（逐件打印、螺旋花瓶、
    圆弧拟合、磨砂皮肤等）自己挑；不挑就等于一个都不改，程序不会替你开。
· 支撑现在真的按模型判断了：模型有悬垂会自动帮你开支撑（并提醒你去 Studio 看一眼落点），
  没悬垂的件不会乱开。悬垂在上部的件，支撑接触面会多给一层。
· 一大片悬空的件（比如桥、悬臂），桥接速度会被压到 30 mm/s 以下，避免垂丝。
· 「方案」那一行去掉了：选模式 + 机型/耗材/喷嘴/板子/室温/风扇/支撑 本身就是
  一套方案，不用再多存一层。
· 打印板下拉改成中文，并且只留 Studio 真有的五种：「超粘板 Supertack / 纹理 PEI 板 /
  高温板（含光滑 PEI）/ 工程板 / 低温板」。光滑 PEI 在 Studio 里就是高温板
  （共用 hot_plate_temp），不再单列；换机型时下拉还会按官方 not_support_bed_type
  过滤（H2C/H3C/P3C 没有低温板与高温/光滑 PEI，A2L/X2D 没有低温板）。
· 室温是一个普通输入框：空着就不动，敲 8 就是 8°C，敲完自动重算。
  （以前用带小箭头的数字框，「0」既表示不指定又可能是真的 0°C，会打架。）
· 风扇强弱默认「自动」：按耗材和室温自己定（冷天自动降一档）；
  想插手就在下拉里选「比标定低 20% / 高 20%」等档位，选了就照你给的来。

------------------------------------------------------------
三、它到底改了什么（重要）
------------------------------------------------------------
· 只改你加载的那一份工程文件，另存为新文件，**原始 3mf 一个字节都不动**。
· 绝对不碰 Bambu Studio 的任何预设（耗材/工艺/机型）：
  目标若落在 Studio 预设目录里会直接拒绝写入，保存后还会再核对预设目录指纹。
· 写入范围（v1.2 起）：
    ① 切片工艺页：速度、加速度、层高、线宽、支撑、接缝等。
    ② 热床温度与风扇转速（这两项在 Studio 里属于耗材页，按
       「耗材 × 板子 × 室温」推导，天冷不翘边就靠它）。
    ③ 机器页：**只在你在界面上换了机型时**才重写（机型名、板面尺寸、
       机器上限），并同时提醒你去 Studio 做一次校准。
· 仍然只读不改的：压力提前、回抽、流量比、AMS 槽位、喷头温度曲线。
  这些只用来约束工艺参数的上下限。

------------------------------------------------------------
四、v1.2 修了什么（如果你用过往版本）
------------------------------------------------------------
1. 「参数有时生效有时不生效」：
   以前只把改动声明进工程的**工艺槽**，热床温度和风扇是耗材页的键，
   声明是空的 → Studio 按耗材预设把它们盖回默认值。现在工艺 / 耗材 / 机器
   三个槽分别声明，声明过的键 Studio 才会采用文件里的值。
2. 「选了机型后生成的 3mf 不对应」「手选机型后参数又变回默认」：
   以前从不重写机器页，Studio 按机器页认机型，就会用旧机型的预设重算。
   现在按你选的机型重写机器页并声明进机器槽。
3. 新增：热床与风速按耗材×板子×室温推导；支撑「好拆 / 极好拆」两档；
   圆柱件的斜接缝（侧面那条竖线基本看不见，代价约慢 2~5%）；
   风扇强弱「自动档」（按耗材和室温自己定，也可手选档位）；结论卡；保存后逐键核对。

------------------------------------------------------------
五、第一次打开工程后请核对这几件事
------------------------------------------------------------
1. 识别出的机型 / 耗材 / 喷嘴是否对（错了在界面上直接下拉改）。
2. 「真机同步」那一行显示的上限是不是你这台机器的真实值。
3. 打开导出的 3mf 看：
   · 工艺 → 速度：外壁/内壁/空走速度应该已经变了；
   · 耗材 → 热床温度、风扇：应该是你设的板子和室温算出来的值；
   · 机型：应该是你在界面选的那台。
   如果没变，看下一条。

------------------------------------------------------------
六、常见问题
------------------------------------------------------------
Q: 打开导出的工程，参数好像没变？
A: 先确认你打开的是新生成的那份（文件名带 _optimized_v2_时间戳），
   再试 文件 → 重新加载。
   如果仍然没变，把保存区那个「把工艺档标为自定义」勾上再存一次：
   它会把工程内部的工艺档名改成「原名 - Smart Tuner」，
   Studio 就不会按同名系统预设去覆盖文件里的值。

Q: 天冷打印翘边怎么办？
A: 在识别面板把「室温」填上真实房间温度（比如 8），
   板子选你实际用的那块（Supertack / 纹理 PEI / 高温板…）。
   程序会按「耗材 × 板子 × 室温」把热床温度加上去（越冷加得越多），
   低于 18°C 时风扇也会自动再降一档。
   还不够就再把「风扇偏置」往负数拉（比如 -10）。

Q: 支撑太硬、拆下来崩面？
A: 把「支撑好拆」选成「好拆」或「极好拆」：程序会放大支撑顶面与底面的
   Z 间隙、减少接触面层数、放宽接触线距。
   注意支撑**落在哪里**只能你在 Studio 里用刷子判断，程序只调参数。

Q: 圆柱体侧面的接缝能弄好看点吗？
A: 默认会做。程序按几何认出圆柱/圆管后，把接缝对齐成一条竖线并整套打开
   斜接缝（scarf joint），那条竖线会被斜面盖住。
   代价是整体慢约 2~5%（结论卡里会写）。不想要就取消勾选「圆柱/圆管接缝做斜接」。

Q: 想固定几套参数下次直接用？
A: 界面有「方案」下拉，内置三套（快速出件 / 外观优先 / 冷天不翘边），
   也可以设好之后点「存为方案」。方案存在
   %APPDATA%\BambuSmartTuner\presets.json，删掉程序不影响。
   注意方案存的是「你选了什么」而不是固化的数值，
   所以规则库升级后它会自动用上新规则。

Q: 保存完程序说「自检发现写入不一致」？
A: 那说明写进 3mf 的值和界面上显示的不一样，把日志里那一行连同工程一起发回来。
   正常情况这一行不会出现。

Q: Studio 弹出「交替额外墙层」的一致性提示？
A: 那是 Studio 要求「交替额外墙层 / 确保垂直外壳厚度=部分 / 墙层数=2」
   三个键成套。程序会自动处理（把墙层数提到 4 圈以上时会关掉交替额外墙层
   并在日志说明）。想保留该功能就改用均衡档。

Q: 杀毒软件报毒 / 提示未知发布者？
A: 单文件打包的 Python 程序容易被误报（PyInstaller 常见现象）。
   程序没有联网代码、没有安装行为。加白名单即可；
   介意的话把源码目录一起给你，自己 pip install -r requirements.txt 跑 python app.py。

Q: 想改调参规则？
A: 直接编辑 rules\BambuRules.json，重开程序即生效，不用重新打包。
   参数含义见 README 的规则库章节。

Q: 想改「Studio 里在哪」的定位？
A: 编辑 data\studio_ui.json，同样是重开生效。

------------------------------------------------------------
七、出问题了怎么反馈
------------------------------------------------------------
把这三样发回来即可定位：
1. 界面「日志 / 优化说明」框里的全部文字（右键可全选复制）；
2. 你的工程文件（或它的 printer_model / filament_type / nozzle 三个值）；
3. 你选的机型/耗材/模式，以及打印板、室温、支撑好拆、接缝这几个下拉的值。
